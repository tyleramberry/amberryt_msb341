# Sprint 3 Plan

**Goal:** A working prototype of a B2C personal AGI model benchmarking product.

**Why this:** Homeroom's validation didn't go as well as I thought, so now is a good time to
pivot. This product is better aligned with my beliefs and first principles: each person should
own their own intelligence, and part of owning your own superintelligence is knowing which model
to use. Right now it is nearly impossible to keep up with model releases, let alone tell which
model is good for personal intelligence and agent use cases. A product that tells you which model
is good for the work you actually do is crucial.

**Done looks like:**
- A live app with a link, with its code in this repo.
- One person other than me (my wife) uses the product to work out a set of personal evals. She
  goes through the product, not a process I run by hand.
- The product tests 3 to 5 models on those evals and outputs her personal benchmark: a table
  ranking the models on the different evals.
- The pivot is recorded: a decision record in `decisions/`, and `README.md` and `AGENTS.md`
  updated to describe the new product.

**Predicted difficulty:** 4
