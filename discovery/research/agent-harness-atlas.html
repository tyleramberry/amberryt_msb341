Agent Harness Atlas

A harness is everything around the model: the loop, the tools, the context it loads, how it remembers and how it's kept safe. This page compares Codex, OpenCode, Hermes Agent, OpenClaw and Pi. It shows what all five share, which is the core of a harness, and what each does that the others don't.

Building your own: a suggested order

The order is the point here: each layer depends on the ones before it. Get the first four working and you have a usable harness, which is roughly where Pi stops. Everything after that is a product decision.
