## 2. Existing products (seen on X)

- **Arena / LMArena** ([@arena](https://x.com/arena/status/2024934480386171121)): crowd-voted, side-by-side leaderboard built from real prompts. It added [AutoEval](https://x.com/arena/status/2085380299371037017) (Aug 2026, 81 L) and open-sourced [Arena-Rank](https://x.com/arena/status/2001729383518867582). The rankings are aggregate, not personal.
- **Braintrust** ([@braintrust](https://x.com/braintrust/status/2090851850719264941)): developer eval platform with an open eval library, playgrounds and an MCP server. Its ["Evals are the new PRD"](https://x.com/braintrust/status/2039356267949445230) post got 129 L and 363 B. It is built for teams, not individuals.
- **Together "which open model" site** ([@nutlope](https://x.com/nutlope/status/2102446473019330737), Sep 22, 2026, 253 L, 202 B): compares open models by category, cost and quality. It was the top-engagement launch in these searches. It uses benchmark categories, not your own prompts.
- **Test AI models** ([@anujcodes_21](https://x.com/anujcodes_21/status/2026218547580719520), Feb 2026, 62 L, 31 R): "Benchmarks test 'write a poem.' You need to test YOUR prompts." Runs ChatGPT, Claude and Gemini side by side, with no API keys needed.
- **MoltSearch** ([@OneManNoCode](https://x.com/OneManNoCode/status/2036103859219599450)): tests Gemini, Claude, ChatGPT and Grok side by side on your prompts in one chat.
- **byself** ([@byselfai](https://x.com/byselfai/status/2113608841967599784), Oct 2026): Mac app that runs one prompt across 16 models, with privacy first.
- **Hyperagent** (mentioned by [@archygupta22](https://x.com/archygupta22/status/2077058966446887091)): compares models for a person's own use.
- **PromptPit** ([@promptpit](https://x.com/promptpit/status/1995474076433776694)): arena where you vote on model outputs for your own prompts.
- **Model comparison by specs** ([@ZakBuildsAi](https://x.com/ZakBuildsAi/status/2050460284054274182), [@geokanello](https://x.com/geokanello/status/2054834052243267881)): compares price, context window and capabilities. These are static catalogs.
- **Routers and auto-pickers**: [Hopscotch](https://x.com/HopscotchAI/status/2104949640873599295) (500+ models, 101k imp), [GitHub HydraFusion](https://x.com/kaddisdeployed/status/2096842071134925081) (sends each coding task to the best-suited model), [TrustedRouter](https://x.com/Growth_100x/status/2096117652544688334), and "Auto mode" pickers ([1](https://x.com/OneLoveAllEqual/status/2108070193343635848), [2](https://x.com/Temitope_Fire/status/2085413132424388698)). OpenRouter is in the same category.
- **Niche or local**: [Future AGI](https://x.com/FutureAGI_/status/1987930291848310996) (A/B tests voice stacks on your own scripts), a [local LLM eval platform](https://x.com/cheeez42/status/2063586668787994718), and a [local eval Chrome extension](https://x.com/konstantinsio/status/2093027462649167893).

## 3. Recurring pain points

1. **Benchmarks are gamed or don't match real work.** Labs optimize for leaderboards, while users care about reliability, retries and long tasks.
2. **Vibe checks don't scale.** Even experts like Shreya Shankar stop trusting their own impressions, but building a real eval set is too much work for most people.
3. **Testing every new release costs time and usage limits.** People burn quota trying each model, then go back to what they had.
4. **New models can regress.** A newer model can be worse on someone's specific tasks, and nothing warns them.
5. **What people want is per task, not one overall winner.** "Which model for *this* task," weighed against cost.
6. **People don't know which tools exist.** The "what tools should I look at?" question gets asked directly.

## 4. Verdict

The demand is real, but it is scattered and engagement is moderate. The loudest voices are developers and power users. The space is crowded at both ends:
- **Developer eval platforms** (Braintrust, Promptfoo, Arena) are powerful but need setup.
- **Side-by-side chat apps** are easy to use but stop at one-off comparisons, with no memory and no scoring.

**The gap is in the middle:** a personal benchmark for non-engineers. It would:
- build an eval set from your real past chats and tasks,
- rerun it automatically whenever a new model ships,
- score the results with an LLM judge plus your own ratings,
- recommend the best model per task, weighed against cost and usage limits,
- warn you about regressions.

Every's "personal benchmark" post and Shreya Shankar's post describe this exact need, and no mainstream consumer product owns it yet.

## Limits of this research
- X search does not support engagement filters, so results were sorted by relevance.
- 5 searches were run with no rate-limit problems (994 of 1,000 daily reads left).
- Linked product sites were not opened or checked.
- Promptfoo, OpenRouter, Martian and Not Diamond posts did not come up in the search.
